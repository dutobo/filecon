# Changelog

## 0.3.1

- The README shows a screenshot of every theme (light and dark).

## 0.3.0

- New icon theme: Filecon Iconic, with a standalone, self-drawn symbol per file type instead of a page shape
  (redrawn marks for brand formats), in light and dark variants.

## 0.2.0

- Five new icon themes: Filecon Papered, Filecon Papered Flat, Filecon Papered Craft, Filecon Scratch and
  Filecon Chalk, each with light and dark variants.

## 0.1.0

- Initial release: three file icon themes (Filecon, Filecon Gray, Filecon Solid) with light and dark variants,
  mapping 650+ file extensions, exact file names (`Dockerfile`, `Makefile`, `Thumbs.db`, …), 116 VS Code
  language ids and a folder icon.
