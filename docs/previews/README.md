# Previews

README images of Filecon, rendered from the real SVGs by `tools/previews/render.py` (`pnpm previews`). Every image
shows the light theme on the left and the dark theme on the right. The READMEs of the npm packages, crates, the
Python package and the VS Code extension link to these files; the images are never part of a package.
