# @filecon/elements

## 0.3.0

### Minor Changes

- Add the Iconic style: a standalone, self-drawn symbol per file type instead of a page shape, with redrawn marks for brand formats, in light and dark. `Style` gains `"iconic"`, every framework gets an `@filecon/<fw>-iconic` package, `@filecon/iconify` adds the `filecon-iconic` and `filecon-iconic-dark` sets and `@filecon/css` adds `iconic.css`, `iconic-light.css` and `iconic-dark.css`.

### Patch Changes

- Updated dependencies
  - @filecon/js@0.3.0
  - @filecon/shared@0.3.0

## 0.2.0

### Minor Changes

- Add five new icon styles generated from the icon pack: `papered`, `papered-flat`, `papered-craft`, `scratch` and `chalk`, each in light and dark (plus `auto`). The all-styles packages now carry all eight styles; every framework gets one package per new style.

### Patch Changes

- Updated dependencies
  - @filecon/js@0.2.0
  - @filecon/shared@0.2.0
