## 0.3.0

### Minor Changes

- Add the Iconic style: a standalone, self-drawn symbol per file type instead of a page shape, with redrawn marks for brand formats, in light and dark. `Style` gains `"iconic"`, every framework gets an `@filecon/<fw>-iconic` package, `@filecon/iconify` adds the `filecon-iconic` and `filecon-iconic-dark` sets and `@filecon/css` adds `iconic.css`, `iconic-light.css` and `iconic-dark.css`.
